## 2. C언어 복습 (part3,part4)
### 포인터 (변수)
포인터 변수의 크기 : 8 byte
( 주소를 저장할 수 있는 크기 )

### * (deference 연산자, 참조연산자)
\* 는 이항 연산자로 쓰이면 곱하기, 단항 연산자로 쓰이면 참조 연산자

int * p; " p 에는 메모리 주소가 담겨있는데, 그걸 "따라가면" int 가 나옴 " 

따라가면 에 해당하는 것이 \* 임 ( printf("%d", \*p);

### 배열

배열의 이름 == 주소 상수

int array[] = { 1,2,3 };
\*(array + 2) = 0 로 배열 원소에 접근 가능.

### Call-by-Value
함수에 인자를 넘길 때 C는 값을 " 복사 ' 해서 넘긴다.
### Call-by-reference 
서로 같은 메모리 주소를 쓰는데, 이름만 여러개 붙은 것일 경우 call by reference 라고 한다.

### EOF
파일의 끝을 의미
처리할 파일의 끝일 뿐이지, 프로그램의 종료를 의미하지는 않는다.
파일 작업을 하다가 EOF 가 읽히면 파일 작업을 중단해야 한다.

### 메모리 적재될 때 변수의 주소 변경 문제
상대 주소를 사용 : 고정된 숫자가 아니라 " 어떤 기준점 대비 몇바이트 떨어진 위치 " 같은 형태로 저장

### STACK
모든 지역 변수는 절대 주소가 아니라 상대 주소를 쓴다.

FRAME POINTER (FP) 로 부터 몇 바이트 떨어졌는지를 이용

함수가 호출되면 프레임포인터를 변경 시키고, 이제 호출된 함수는 변수 접근할 때마다 프레임포인터를 기준으로 상대 주소를 이용.
함수가 종료되면 프레임포인터를 원래대로 되돌린다.

LIFO 처럼 메모리 공간의 수명주기가 엄격하지 않고 원하는 시점에 할당하고 해제 가능한 방식이 필요함 --> HEAP

### HEAP
메모리 할당 순서, 반환 순서 관계 없이 사용할 수 있는 메모리를 heap 이라고 한다.

즉, HEAP 은 할당과 해제의 순서에 관계 없이 필요할 때 할당하고 해제 되는 메모리

### void \*

타입과 관계 없이 주소 값을 저장하는 목적으로 사용한다.
```cpp
void *ptr
ptr = &i;
`````
### malloc
할당할 전체 메모리 사이즈를 인자로 넘김
```cpp
malloc (sizeof(int) * 4);
`````

### calloc
calloc 은 반환하는 메모리를 0 으로 초기화한다.
원소 개수, 각 원소의 크기를 명시해야 한다.
```cpp
parray = calloc(4, sizeof(int));
`````
### realloc
기존에 할당 받은 메모리의 크기를 변경해서 새로 할당하고자 할 때 사용
기존 메모리의 내용을 새 메모리에 복사할 수 있는 만큼 복사하고, 기존 메모리는 해제

realloc = malloc + memcpy + free
### free
malloc,calloc,realloc 으로 할당 받은 메모리를 해제
